#  TuTubo 

Plataforma de videos hecha en un solo archivo HTML, sin frameworks ni instalación. Crea tu cuenta, sube videos y shorts, comenta y publica en la comunidad. Todo se guarda en Firebase, así que cualquiera con el enlace ve lo mismo que tú.

Incluye: inicio con videos recientes y más vistos, shorts verticales, comunidad con publicaciones y likes, comentarios, página de reproducción grande con lista de siguientes, tema claro/oscuro y diseño adaptable a celular.

Hecho con: HTML, CSS y JavaScript puro + Firebase (Authentication y Firestore).
